# SIGNUM — браузерный тактический шутер

**Signum** (лат.) — знамя легиона, знак и сигнал к атаке: то, вокруг чего
держится строй. Браузерная игра на three.js.

Из чего собрана игра (папка `game/`):

| Страница | Что это |
|---|---|
| `start.html` (`index.html` → сюда) | Лобби: полигон с четырьмя генералами, меню «В бой / Настройки / Оружие». |
| `armory.html` | Оружейная: 8 стволов, полигон с мишенями и модулями, 6 слотов снаряжения. |
| `forest.html?battle` | Бой на карте «Тихий бор»: 4 генерала × 20 бойцов = 84 персонажа. |
| `hangar.html?battle` | Бой на карте «Ангар-07»: 4 генерала × 10 бойцов = 44 персонажа. |
| `weapons/*.html`, `grenades/*.html` | Исходные файлы оружия и гранат (оружейные полигоны встраиваются в оружейную). |

Без `?battle` карты открываются как раньше (свободный режим).

## Лобби (`game/start.html`)

Первый экран — «два экрана в одном»: слева полигон в сосновом лесу с четырьмя
генералами (Дельта-1 «Кедр», Дельта-2 «Сойка», Альфа-1 «Ворон», Альфа-2 «Тис»),
справа стеклянная панель с кнопками **«В бой»** (алая обводка), **«Настройки»**,
**«Оружие»**. Кадр 3D-сцены смещён (`camera.setViewOffset`), чтобы генералы
стояли в центре левой части.

- **W A S D** — панель уезжает, камера летит по полигону (мышь — обзор,
  `Shift` — быстрее, `Пробел`/`C` — выше/ниже). Камера стоит 5 с — меню
  возвращается; `TAB` — меню в любой момент, `ESC` — меню.
- **Удерживать F** рядом с генералом — он становится выбранным
  (`profile.general`, кольцо цвета команды и звёздочка в подписи), камера
  входит в него (бодикам). Ещё раз удерживать F — выход. Выбор переносится
  на другого генерала так же.
- Генералы стоят **без оружия, руки по швам**. Оружие появляется только у
  генерала, для которого в оружейной собрано снаряжение: основное (или
  пистолет) строится `game/lib/weapons` с модулями из профиля. Вошли в
  вооружённого — вид от первого лица с руками GLB на хватах этого оружия и
  стрельба по мишеням с его характеристиками (темп, магазин, режимы, отдача);
  в безоружного — просто ходьба от первого лица.
- **«Оружие»** → `armory.html?general=<выбранный>` (если никто не выбран —
  случайный генерал, о чём говорит всплывающее сообщение). По возвращении
  (`start.html?from=armory`) оружие пересобирается, первый раз — подсказка.
- **«Настройки»**: вкладка «Управление» — действия по группам (Движение /
  Бой / Взаимодействие), клик по клавише → новая клавиша или кнопка мыши,
  `ESC` — отмена, занятая клавиша меняется местами с другим действием,
  «Сбросить». Вкладка «Графика» — Низкая / Средняя / Высокая (разрешение,
  тени, AO, MSAA — применяется сразу), чувствительность, FOV, громкость.
  Всё хранится в `localStorage['signum:profile']` (`game/lib/profile.js`).
- **«В бой»** → две карточки карт («Тихий бор · Forest Camp», «Ангар-07»):
  снимок сверху (`game/img/map_*.jpg`, без файла — градиент), описание,
  численность и респауны. Клик пишет `localStorage['signum:deploy']`
  (`resolveDeploy` + `map`) и открывает `forest.html?battle=1` /
  `hangar.html?battle=1`. Без выбранного генерала или снаряжения — случайные.
- При первом запуске — пошаговые подсказки (можно пропустить, сохраняются в
  профиле).

## Оружейная (`game/armory.html`)

Слева — список оружия (АК-74М, АКМ, M416, SCAR-H, СВД, Remington 870, MP5A3,
Glock 18C), в центре — оружейный полигон выбранного ствола (страница из
`game/weapons` в режиме `?embed=1`) с панелью модулей справа, сверху — 6 слотов.
Слот — один предмет: основное оружие (только одно), пистолет (только один),
120 патронов к основному, 30/33 патрона к пистолету, граната М67 или М84.
Кнопка «←» сохраняет снаряжение генерала (`profile.loadouts[генерал]`) и
возвращает в лобби — генерал получает это оружие с модулями.

Модели оружия для всех страниц строит `game/lib/weapons` (генерируется
`node game/tools/build_weapons.mjs` из файлов `game/weapons/*.html`):
`buildWeapon(id, cfg)` — полная модель с модулями и точками хвата,
`buildWeaponLite(id, cfg)` — один меш ~4–8 тыс. треугольников для ботов.

## Бой (`game/lib/battle`)

- **Силы.** В каждой команде (Альфа, Дельта) два генерала со своими отрядами.
  Игрок — один из генералов: его отряд штурмует вместе с ним, второй генерал
  его команды (ИИ) держит оборону у флага. У противника так же: один отряд
  штурмует, второй обороняет. Если штурмовой отряд уничтожен и респаунов не
  осталось, половина обороны уходит в разведку.
- **Респауны.** Лес: бойцы 3, генералы 4. Ангар: бойцы 2, генералы 3. Бойцы
  появляются на своей базе с полным боезапасом; пополниться можно у ящиков
  (игрок — удерживая `F`, боты — сами).
- **Цель.** Дойти до флага противника и удерживать `F`, пока он не будет
  уничтожен (боты захватывают сами), или уничтожить всю живую силу противника.
- **ИИ.** Сетка проходимости по коллизиям карты, A* и поле расстояний к
  флагам, точки укрытий у препятствий. Бойцы видят в секторе обзора, с учётом
  линии видимости и времени обнаружения; под огнём ищут укрытие, садятся,
  стреляют очередями с человеческой ошибкой наводки, не стреляют, если на
  линии огня свой, бросают гранаты за укрытие и убегают от чужих. Отряд
  игрока идёт вокруг него врассыпную на 5–10 м, не перекрывая сектор перед
  ним; когда игрок стоит — занимает укрытия.
- **Урон.** Голова или корпус — одно попадание, руки и ноги — два (после
  первого боец ранен: хуже целится, медленнее ходит). Огонь по своим включён.
  М67: осколки по закону обратных квадратов с учётом укрытия (≈ смертельно
  до 5 м, потери до 15 м, дальше — редкие ранения), взрывная волна до 2 м,
  разрушения — физика карты. М84: ослепление и оглушение по дальности и
  направлению взгляда. Взрывы самой карты (мины, бочки) тоже ранят бойцов.
- **Реализм интерфейса.** Прицельной марки нет — только прицел оружия.
  Противник не подсвечивается. Свои — маленькая синяя метка над головой,
  отмеченные для приказа — зелёная.
- **Приказы.** `X` — отметить своего бойца, на которого смотрите. `M` —
  тактическая карта: вы — красный, отмеченные — зелёные, свои — синие; клик —
  отмеченные выдвигаются в точку и занимают там укрытие, ПКМ — снять
  отметки, «Вернуть в строй» — отменить приказы.
- **Бойцы** — те же модели, что генералы в лобби (у ботов свой камуфляж и
  нашивка отряда), оружие — облегчённые модели оружейной: свои с АК и СВД,
  противник с M416 и SCAR-H.
- **Оптимизация.** Общая геометрия бойцов, LOD-индексы (meshoptimizer),
  мелкие меши лица и тени только вблизи, поза реже для дальних и невидимых,
  бюджет лучей видимости с кэшем по парам, бюджет A* на кадр, ограничение
  полифонии выстрелов. Логика 84 бойцов — ~1–3 мс на кадр.

Карты подключаются через `game/tools/patch_maps.py` (экспорт нужных функций,
хук кадра, загрузчик), модели бойцов для боя собираются
`node game/tools/build_battle.mjs`.

## Запуск

Игра открывается с веб-сервера (GitHub Pages или локально) — страницы
подключают ES-модули `game/lib/*`, поэтому `file://` не поддерживается:

```sh
cd game && python3 -m http.server 8000
# http://localhost:8000/  (index.html -> start.html)
```

Управление по умолчанию (переназначается в «Настройках»): `WASD` — движение,
`Shift` — бег, `C` — присесть, `Пробел` — вверх (свободная камера), `ПКМ` —
прицел, `ЛКМ` — огонь, `R` — перезарядка, `B` — режим огня, `F` (держать) —
выбрать генерала / выйти, `TAB` — меню, `V` — осмотр, `Q/E` — наклон,
`P` — вид от третьего лица.

## Модули

Игра собирается из модулей `game/src` в один файл `game/start.html`:

```sh
node game/tools/build.mjs
```

| Модуль | Что внутри |
|---|---|
| `viewmodel/vm.js` | **Руки, хват, пальцы, бег от первого лица** — перенесено из `bodycam_angar.html`: перчатки GLB с костями пальцев, процедурные рукава со складками у локтя и манжетой, риг оружия (наготове, прицел, бег, упор), покачивание, отдача, анимация перезарядки. |
| `viewmodel/hand_assets.js` | Модели кистей (GLB, встроены в страницу — работают и из `file://`). |
| `viewmodel/wspec.js` | **Спека рига для любого оружия** (`self.GWSpec`): хваты и прицел рига строятся из `anchors` сборки `game/lib/weapons` (правая кисть — `grip`, левая — `support`, прицел — `eye`), отдача и темп — из `stats`. |
| `viewmodel/hands.js` | **Кисти GLB на скелете бойца** (`self.GHands`), не зависят от оружия: `attachHands(char, assets)`, `wristQuat`, позы пальцев `POSES.relaxed`. |
| `anim/pose.js` | **Поза бойца со стороны** (`self.GPose`): корпус, ноги по походке `anim/locomotion.js`, голова по направлению взгляда (часть поворота берёт корпус), присед, дыхание, «жизнь» в строю, опора стоп, LOD, падение при гибели. Общая для лобби и ботов. |
| `weapon/hold.js` | **Оружие в руках бойца со стороны** (`self.GHold`) — генералы в лобби и боты на картах. См. API ниже. |
| `game/lobby.js` | **Меню лобби** (`self.GLobby`): карточка генерала, «Настройки» (клавиши, графика), «В бой» (карты, `signum:deploy`), «Оружие», подсказки первого запуска. |
| `game/bodycam.js` | **Шлемная камера**: вид от лица бойца на уровне глаз (на одной высоте с глазами остальных). Наведение как в `bodycam_angar.html`: мышь ведёт автомат руками (локти сгибаются), голова с камерой догоняет его пружиной; в прицеле целик и мушка приходят в центр кадра. Бег: качание по фазе шага (та же, что у звука и ног), наклон корпуса, скрутка плеч, крен в повороте, отставание головы при разгоне и торможении. Линза бодикама (рыбий глаз, хроматизм, смаз, шум), без зума. |
| `soldier/body.js` | **Туловище.** Атлетическое телосложение: дельты, трапеции, грудь, широчайшие, шея, бёдра — поле объёмов вокруг костей, одинаковое для всех слоёв (кожа, китель, жилет), поэтому ничего не прорастает. |
| `soldier/clothing.js` | **Одежда.** Крой (объёмные рукава, напуск брюк над берцами), камуфляжи под референс (мультикам с «ветками», серо-зелёный, чёрный, чёрно-зелёная цифра), складки ткани на локтях, манжетах, коленях и поясе, пыль и потёртости, бархатистый отлив ткани. |
| `soldier/gear.js` | **Снаряжение.** Наколенники (Дельта-2, Альфа-1, Альфа-2), нашивки подразделения на рукавах. |
| `anim/locomotion.js` | **Походка ног со стороны.** Ключевые кривые суставов для шага и бега (фаза полёта, вынос колена, захлёст голени, перекат стопы), вращение и наклон таза, встречный поворот груди, реальный каденс. Вариации: у каждого бойца своя стойка, перенос веса, повороты головы. |
| `soldier/rig.js` | IK рук, распределение скрутки предплечья, опора стоп. |
| `soldier/character.js` | Сборка бойца: скелет, меши, материалы, пресеты четырёх форм. |
| `game/game.js` | Сцена лобби: генералы и их оружие из профиля, свободная камера и меню (смещение кадра, возврат через 5 с), выбор генерала по F, бодикам, стрельба по мишеням, качество графики, подписи генералов. |
| `game/player.js` | Контроллер: движение с весом, выносливость, отдача. |
| `world/*`, `core/*` | Лес и стрельбище, эффекты, утилиты; `core/boot.js` подключает `lib/profile.js` (`self.GProfile`) и грузит `lib/weapons` как ассет. Звук (`world/audio.js`) идёт через тракт микрофона бодикама (срез низа и верха, подъём присутствия, перегруз, жёсткий компрессор); шаги по лесной подстилке, дыхание в ритм бега, ветер в микрофоне на ходу. |

### `GChar`, `GPose` — бойцы для карт

```js
const char = GChar.build(THREE, 'alpha_1', { camo: 'olive', head: 'helmet', mask: false, patchCol: [[40,40,44],[220,60,60]] });
// camo: GChar.CAMOS — delta_green, delta_grey, alpha_black, alpha_cadpat, flora, woodland, olive, coyote, urban
// другие поля: GChar.VARIANT_KEYS; материалы одного варианта общие для всех его бойцов
const pose = GPose.create(THREE, char, { rig?, seed? });           // pose.rig — риг для GHold
pose.update(dt, { x, y, z, yaw, vx, vz, crouch, aimYaw, aimPitch, t, lod, ready?, groundAt? });
pose.die(dirX, dirZ); pose.revive();                                // падение ~0,6 с
```

### `GHold` — оружие в руках бойца

```js
const h = GHold.create(THREE, { char, rig });   // char — GChar.build, rig — new GRig.Rig
h.setWeapon(build | null);   // WeaponBuild из game/lib/weapons (buildWeapon / buildWeaponLite)
h.setState('unarmed' | 'low' | 'ready' | 'aim');   // по швам / у груди / наготове / в прицеле
// каждый кадр ПОСЛЕ позы корпуса и ног:
h.update(dt, { yaw, pitch, ik: true, fingers: true, trigger: 0 });
// ik:false — дальние боты: оружие ставится, руки не решаются (дёшево)
h.muzzleWorld(v3); h.forwardWorld(v3); h.snap(); h.dispose();
```

Модули бойца (`core/util.js`, `soldier/*`, `anim/locomotion.js`, `anim/pose.js`,
`viewmodel/vm.js`, `viewmodel/hand_assets.js`, `viewmodel/hands.js`,
`viewmodel/wspec.js`, `weapon/hold.js`) не зависят от лобби и подключаются
на картах боя.

## Проверка

`game/tools/shots.mjs` снимает кадры headless-браузером (Playwright,
WebGL через SwiftShader) и позволяет управлять игрой через `window.__GAME`
(`view`, `embody`, `setInput`, `step`, `pause`, `spectate`, а также `ready()`,
`menu(on)`, `key(code, down)` — клавиша через привязки профиля, `select(key)`,
`armAll()`, `profile()`, `info()`, `gripCheck()`, `lobby`). Режим `?dev` в
адресе отключает MSAA и AO — для быстрых проверок.

```sh
npm i playwright && npx playwright install chromium
node game/tools/shots.mjs shots.json out/
```

Скриншоты — `game/screenshots/`.
