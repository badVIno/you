# Полигон «Дельта / Альфа» — бойцы

Браузерная игра на three.js: четыре оператора (Дельта-1, Дельта-2, Альфа-1,
Альфа-2) на стрельбище в сосновом лесу. Можно сесть за любого бойца (F),
бегать, целиться и стрелять из модульного АК-74.

## Запуск

- **Одним файлом:** открыть `game/start.html` в браузере. Ассеты (модель
  бойца, текстуры, окружение) подтянутся с jsDelivr.
- **С локального сервера** (ассеты берутся из `game/assets`):
  ```sh
  cd game && python3 -m http.server 8000
  # http://localhost:8000/start.html
  ```

Управление: `WASD` — движение, `Shift` — бег, `Ctrl/C` — присесть, `ПКМ` —
прицел, `ЛКМ` — огонь, `R` — перезарядка, `X` — режим огня, `F` (держать) —
сесть за бойца / выйти, `TAB` — модули оружия, `V` — осмотр, `Q/E` — наклон,
**`T` — вид от третьего лица** (видно походку и хват).

## Модули

Игра собирается из модулей `game/src` в один файл `game/start.html`:

```sh
node game/tools/build.mjs
```

| Модуль | Что внутри |
|---|---|
| `soldier/hands.js` | **Пальцы и хват.** Процедурная тактическая перчатка по суставам модели (ладонь, 4 пальца × 3 фаланги, большой палец с тенаром, манжета с липучкой, жёсткие накладки на костяшках, замшевая ладонь, швы). Хват задаётся от оружия; ладонь досаживается на поверхность, каждая фаланга сгибается до касания рукоятки/цевья (SDF формы АК). Указательный — вдоль ствольной коробки (дисциплина пальца) или на спуске при стрельбе. |
| `soldier/body.js` | **Туловище.** Атлетическое телосложение: дельты, трапеции, грудь, широчайшие, шея, бёдра — поле объёмов вокруг костей, одинаковое для всех слоёв (кожа, китель, жилет), поэтому ничего не прорастает. |
| `soldier/clothing.js` | **Одежда.** Крой (объёмные рукава, напуск брюк над берцами), камуфляжи под референс (мультикам с «ветками», серо-зелёный, чёрный, чёрно-зелёная цифра), складки ткани на локтях, манжетах, коленях и поясе, пыль и потёртости, бархатистый отлив ткани. |
| `soldier/gear.js` | **Снаряжение.** Наколенники (Дельта-2, Альфа-1, Альфа-2), нашивки подразделения на рукавах. |
| `anim/locomotion.js` | **Походка и бег.** Ключевые кривые суставов для шага и бега (фаза полёта, вынос колена, захлёст голени, перекат стопы), вращение и наклон таза, встречный поворот груди, реальный каденс. Вариации: у каждого бойца своя стойка, перенос веса, повороты головы. |
| `soldier/rig.js` | IK рук, распределение скрутки предплечья, опора стоп. |
| `soldier/character.js` | Сборка бойца: скелет, меши, материалы, пресеты четырёх форм. |
| `game/game.js` | Позы оружия: «на ремне» (как на референсе), наготове, прицел, **бег — стволом вниз**; камера (свободная, от глаз, от третьего лица). |
| `game/player.js` | Контроллер: движение с весом, выносливость, отдача. |
| `weapon/*`, `world/*`, `core/*` | Оружие и модули, лес и стрельбище, эффекты, звук, утилиты. |

## Проверка

`game/tools/shots.mjs` снимает кадры headless-браузером (Playwright,
WebGL через SwiftShader) и позволяет управлять игрой через `window.__GAME`
(`view`, `embody`, `setInput`, `step`, `pause`, `spectate`). Режим `?dev` в
адресе отключает MSAA и AO — для быстрых проверок.

```sh
npm i playwright && npx playwright install chromium
node game/tools/shots.mjs shots.json out/
```

Скриншоты — `game/screenshots/`.
